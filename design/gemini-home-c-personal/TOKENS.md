# 方案 C Design Tokens

- 背景：`#F5F4F0`
- 色块：`#EAE6DF`
- 主文字：`#1A1A19`
- 辅助文字：`#4A4844` / `#827E76`
- 强调色：主要依靠砂色块与近黑对比，无高饱和主色
- 字体：Inter、Noto Serif SC
- 字号：正文 16px；品牌标题约 48–96px；编辑标题约 30–48px
- 最大页面宽度：`1440px`
- 阅读宽度：约 640–720px
- 间距：板块 `clamp(4rem, 10vw, 8rem)`
- 圆角：主体基本不用统一圆角；导航为胶囊
- 边框：`rgba(26,26,25,0.1)`，导航 0.5px
- Liquid Glass：`rgba(245,244,240,0.75)`、`blur(12px) saturate(160%)`、轻微 24px 阴影
