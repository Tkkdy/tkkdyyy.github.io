## Current Project data model

### Current schema

`src/content.config.ts` defines projects with:

- identity/copy: `name`, `slug`, `tagline`, `description`
- publication: `status` = `draft | published | archived`
- lifecycle: `projectStatus` = `concept | designing | developing | usable | maintaining | paused | completed | archived`
- optional visual: `cover`, `coverAlt`, `logo`, `screenshots[{src, alt, caption}]`
- technical/links: `techStack`, `liveUrl`, `githubUrl`
- time/curation: `startedAt`, `updatedAt`, `featured`, `homepage{show, order}`
- history: `changelog[{version, date, summary}]`

The distinction between `status` and `projectStatus` is correctly implemented and should be preserved.

### Current content

Only `src/content/projects/morning-radar.md` exists. It has real headline metadata but no cover, logo, screenshots, started date, live URL, GitHub URL or changelog. Its Markdown body declares itself a development fixture.

### Future data considerations — no schema change now

The current model already supports basic screenshots and links, but the evidence-backed homepage may later need:
