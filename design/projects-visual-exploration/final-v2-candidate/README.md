# Projects Homepage — Final v2 Candidate

这是以 Original Direction C 为唯一视觉 Source of Truth 的外科式精修候选稿，不是新的设计方向。

## 设计边界

- 保留 Direction C 的项目层级、非对称配对、不同项目 anatomy 与编辑式留白。
- Morning Radar、Repository Atlas、Context Experiment、Quiet Relay 和 Signal Cabinet 都是静态 editorial surface。
- 只有 Local Index 是可翻转的小型数字物件。
- 引入中性偏冷纸张背景、细微项目边界、A 的短 Intro 和 B 的 serif Ending。
- 不包含 Project Detail，也没有 Production 修改。

## 交互

- 桌面：Local Index hover / keyboard focus 翻面；点击可锁定状态。
- 移动：轻触切换正反面。
- 键盘：Enter / Space。
- Reduced Motion：取消 3D 旋转，保留淡入淡出和可访问状态。

直接打开 `index.html` 即可审阅。
