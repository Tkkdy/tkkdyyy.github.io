# Essays — Personal Universe Journal Candidate

## Scope

This is a prototype-only Essays Index implementation. It adds no production route or production component and deliberately leaves all Essay Detail directions unchanged.

## Blueprint fidelity

The page turns the supplied reference into a maintainable, responsive composition: a left page identity, a central low-contrast paper coordinate map, right book-marginal indexes, and the existing quiet archive below. It does not trace the image or use it as a runtime asset.

## Personal universe

The central SVG is a small, accessible prototype coordinate map, not a dashboard or a knowledge graph. Orbit layers suggest time; light connections suggest only possible thematic proximity. Its warm core connects the overview to the archive rather than becoming a sci-fi visual.

## Fixture and data policy

Only `初中时，我只是想看 YouTube` (2026-08-01) is grounded in current published Essay content. The other six archive entries, every star position, all stage labels, and Theme Index labels are prototype fixtures used to test archive rhythm and interaction. They make no claim about the author's real biography. In particular, the reference image's years are not used.

## Archive preservation

The lower section keeps Direction B's non-card, chronological archive: restrained year/date rail, wide editorial rows, title-first hierarchy, optional summary, and optional light media. Text-only fixtures intentionally remain visually complete.

## Interaction and accessibility

Star nodes are real keyboard-focusable SVG links that point to their archive rows. Hover/focus reveals a quiet title/date label. Theme controls only temporarily highlight related prototype nodes and connections; they never filter, reflow, or hide content. The page includes visible focus styling and a reduced-motion override.

## Responsive behavior

At desktop the overview is a three-part composition. At 980px the right marginal indexes move below the map. At 820px and below the star map stays visible but uses fewer outer geometric layers and omits floating labels; indexes become compact two-column notes and the archive becomes a natural single column.

## Known limitations

The media studies are CSS tonal placeholders because no real Essay cover photography is currently available. This candidate intentionally does not make any recommendation for production schema, data modeling, typography replacement, or Detail-page behavior.
