今晚花了一晚上折腾服务器。

买的时候还挺开心，配置看着也不错，内存、硬盘、Docker，全都能跑。然后一点点配环境、装东西、测网络，搞到最后才发现最关键的问题不是性能，是网。

GitHub 一会儿能开，一会儿 clone 不下来；OpenAI、Hugging Face 直接超时。整台机器像是发动机装好了，油也加满了，最后发现路根本没通。

最搞笑的是，这服务器唯一的用途就是拿来跑 Morning Radar。结果 Radar 最需要访问的，偏偏全是国外服务。

最后退款。

折腾了一晚上，留下的东西只有一堆命令、一点服务器经验，和一个很难提前验证的教训

**有些坑，不买下来你甚至都不知道它在那里。**

娘了个大逼蛋。妈的。
