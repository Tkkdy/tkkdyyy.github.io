# VDVXDV Homepage — Visual Synthesis v0.2

- Status: Design convergence brief
- Purpose: Merge the strongest parts of Prototype / A / B / C into one coherent VDVXDV homepage
- Current phase: Visual convergence only, not production engineering

## 1. Overall conclusion

The four existing homepage explorations should NOT be treated as four competing final designs.

The goal now is to extract the strongest ideas from each version and synthesize them into one coherent visual language that feels like `VDVXDV`.

> Use C as the main structural and layout foundation; use B for color-block rhythm, English typography and the preferred Liquid Glass navigation; use the original prototype for editorial divider lines and small section labels; selectively absorb only clearly-liked local ideas from A.

Approximate influence priority:
- C: 60%
- B: 25%
- Original prototype: 10%
- A: 5%

These percentages are directional, not mathematical constraints.

## 2. C as the main layout foundation

Preserve from C:
- clean, calm, relaxing rhythm;
- strong whitespace;
- sections do not all use the same layout;
- content blocks feel independent but coordinated;
- typography is not mechanically aligned everywhere;
- each section changes composition as the visitor scrolls.

Core principle:

> Unify typography, spacing, grid, color and detail — not every section's shape.

Avoid repeated “title + summary + three cards” patterns.

## 3. B as the visual character layer

### Color blocks
Use large, restrained background color blocks to distinguish major chapters, not every card.

The color system should remain:
- serious;
- restrained;
- refined;
- warm;
- technically precise.

Do not return to the dull gray-green palette.

### English typography
Preserve B's English typography qualities:
- clean;
- modern;
- slightly technical;
- refined;
- not aggressively corporate.

Do not guess exact font names unless available from Gemini output.

### Navigation
Use B as the navigation reference.

The final navigation should:
- be compact;
- occupy less visual area;
- use small-area Apple-inspired Liquid Glass;
- remain easy to read;
- feel warm and precise;
- not become a large floating glass bar;
- not spread glass effects into the main page content.

Navigation typography should balance:
- technical / geek precision;
- Apple-like warmth and approachability.

Avoid extremely thin or heavy text. A variable-font target around 450–500 is a useful starting point, with `VDVXDV` slightly heavier.

## 4. Original prototype as the editorial grammar

Preserve:
- thin divider lines;
- small bilingual/editorial section labels;
- the pattern “divider line → section label → corresponding content”.

Examples:
- `FEATURED / 精选`
- `PHOTOGRAPHY / 影像`
- `PROJECTS / 项目`

Use this as recurring section grammar, but do not overuse it before every small item.

## 5. A as a local reference only

A is not the main foundation.

Keep only clearly-liked local layout ideas. Where A contains an underused empty region, a C-inspired content element may be redesigned into that space.

Do NOT literally copy a C component into A. Recompose it so it belongs to the synthesis system.

## 6. Photography principle

Photography must NOT be forced into one ratio or one card type.

Support:
- portrait;
- landscape;
- square;
- unusual original ratios.

Possible editorial combinations:
- one large landscape image;
- two portrait images;
- one wide image followed by a small image;
- one large portrait with a smaller supporting image;
- asymmetric but ordered groupings.

Avoid:
- uniform 4:3 cards;
- dense Pinterest masonry;
- product-gallery cropping;
- automatic equal-height grids.

Core principle:

> The layout should serve the photograph, not force the photograph to serve a component.

Use few images at once and keep generous whitespace.

## 7. Typography direction

Balance:
- technical precision;
- editorial warmth;
- personal character.

Navigation: slightly thin, but not fragile.
English: follow B's direction.
Chinese: readable, warm, natural.

Do not assume “premium” means tiny gray Chinese text or very thin Song-style typography.

Major titles should avoid the generic AI homepage formula:
- huge centered brand name;
- serif subtitle;
- two pill buttons.

## 8. Color direction

The previous warm beige + near black + muted green palette is not accepted as final.

Problems:
- too close to generic Anthropic/Aesop imitation;
- slightly dull;
- not refined enough;
- somewhat cold / sexless;
- lacks personal taste.

Preferred foundation:
- warm ivory / warm white;
- near black / ink;
- soft neutral surfaces;
- one restrained accent.

Possible accent families:
- dark wine;
- muted copper;
- deep blue-gray;
- restrained reddish brown.

Do not automatically use green as the main accent.

Avoid neon, blue-purple AI gradients, high saturation and glowing cards.

## 9. Section system

The homepage remains a curated static cover.

Suggested sections:
- identity / introduction;
- featured article;
- active project;
- essay or fragment;
- photography;
- about / footer.

Each section should use a different composition while remaining coherent through:
- typography;
- spacing;
- color logic;
- alignment;
- detail language.

Use:
- C-style changing compositions;
- B-style restrained chapter color blocks;
- prototype-style divider lines and section micro-labels.

## 10. Card policy

Reduce cards.

Prefer:
- open layouts;
- divider lines;
- background sections;
- typography;
- whitespace;
- image composition.

Avoid:
- same-radius cards everywhere;
- three identical feature cards;
- heavy shadows;
- glass cards throughout the body.

## 11. AI-template warning signs

Actively avoid:
- generic hero + two buttons;
- centered huge title with filler whitespace;
- three-card SaaS layouts;
- identical rounded blocks;
- unnecessary badges;
- generated marketing copy;
- perfectly repetitive grids;
- meaningless decorative geometry;
- “premium minimalism” created by tiny gray text.

The page should feel authored.

## 12. Motion scope

Still no signature motion in this phase.

Allowed only:
- subtle hover;
- basic navigation feedback;
- simple menu transitions.

Do not implement:
- Apple scroll storytelling;
- parallax;
- Liquid Glass morphing;
- particles;
- section entrance animation;
- mouse tracking.

The static design must work first.

## 13. Final target

The synthesis homepage should feel:
- simpler than SSPAI;
- warmer than Vercel;
- less corporate than Anthropic;
- more personal than a standard developer portfolio;
- more structured than an art portfolio;
- calmer than a community homepage;
- visually distinctive without being difficult to use.

Target feeling:

> Clean, premium, serious, warm, technically literate, relaxing, and clearly authored by a real person.

## 14. Acceptance criteria

Synthesis v0.2 is successful when:
- C's calm, asymmetric section rhythm is clearly present;
- B's color-block logic is visible but restrained;
- B-inspired Liquid Glass navigation is compact and refined;
- prototype-style divider lines and section micro-labels are integrated;
- A contributes only useful local ideas;
- photography supports mixed aspect ratios;
- the page no longer feels like a standard AI-generated personal homepage;
- navigation is technical but approachable;
- desktop and mobile remain clear;
- no complex motion is required;
- the result feels coherent rather than collaged.

If the user likes approximately 80% of this version, stop broad visual exploration and move to production architecture research.
