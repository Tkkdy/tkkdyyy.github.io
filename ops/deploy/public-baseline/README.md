# Independent public baseline observation

This is a read-only current-preview observation, never an owner-publish verdict. No SSH, secrets, production Variables/policy, Nginx, current, certificates, builds, or deployment jobs are used.

Runtime: standard GitHub ubuntu-24.04 runner; official Playwright Noble amd64 container pinned by SHA256 d65108d1a8095d8b0c4a5e32bf1807a40a5ce90ff0c78473e1116b1c243235e8; Node24.19.0; locked npm dependencies/Playwright1.64.1; full Chrome for Testing156.0.8078.4. The script verifies actual runtime and the no-proxy flag. Chrome uses its browser network stack; APIRequestContext uses Node https/OpenSSL HTTP1.x. They are explicitly recorded separately. Hosted runner hardware/egress IP can vary; container content is pinned, not the Internet route.

Trigger: one push of .github/public-baseline-run.json on codex/public-baseline-observer. Code-only pushes do not trigger it. run_attempt must equal1; no workflow rerun, request retry, alternate network or fallback. A fresh explicit request is needed for any subsequent baseline. Manual workflow_dispatch would require default-branch registration, so no main change or PR merge is needed here.

One job performs neighbour entries, all115 frozen original files on both domains, original preview SEO/sitemap/RSS/robots, the existing browser_gate (only CfT channel support added), and real Chrome desktop/mobile routes/details/images/Pagefind search and result navigation. First failed check stops all subsequent checks; remaining items are UNVERIFIED. TLS validation stays strict; each public API request/navigation has a30-second deadline and maxRetries=0, redirects are inspected rather than followed. Existing shorter image/search waits are retained. The baseline expects both domains noindex and preview.boenbot.top canonical: current public content has not been migrated.

Identity: preview-manifest.json is the original frozen115-file manifest bdbd0dff0af30ac2b7c3631f22b3228ef501a0f5dcfe6203ed4055c3a5ebd6a0. Body lengths and SHA256 must match; do not update expected content from a new network response. No main source content is built or published.

Diagnostics: passive Node diagnostics_channel observes lookup/connect/secureConnect/headers/body/error, remote IP/family, reused socket, deadlines and cf-ray. It does not patch or replace HTTP clients. Chrome CDP records document addresses/protocol/timing and failures. Transport failure is CLIENT_TRANSPORT_INCONCLUSIVE about service health and still FAIL for this baseline; observed wrong status/content/SEO is a response/identity failure. Deadline-induced socket cancellation must not be counted as another unsolicited reset. Only filtered public headers are saved; no cookies or OAuth redirect query is exported.

Reports and screenshots are retained as a7-day Actions artifact. A successful baseline proves one complete observation from this environment at that time, not long-term reliability, candidate acceptance or indexing activation. A future owner-publish integration must separately bind reviewed observer/runtime/artifact identity and exact verdict token; this workflow cannot authorize deployment and does not create a new owner attempt.
